# Перенос лайков из Яндекс Музыки в Spotify

Локальный сервис: работает только на вашем компьютере, открывается в браузере (Brave) по адресу
`http://127.0.0.1:8888`. Переносит «Мне нравится» из Яндекс Музыки в Spotify **в «Любимые треки»**,
**в плейлист** или в оба места сразу.

Что умеет:

* загружает лайки из Яндекс Музыки, ваши плейлисты и любой открытый плейлист по ссылке (например, лайки друга);
* ищет каждый трек в Spotify по ISRC, а если его нет — с учётом транслитерации (Кино ↔ KINO), ремиксов, длительности и альбома,
  экономя дневной лимит Spotify;
* уверенные совпадения принимает сам, спорные показывает вам для выбора; ненайденное можно поискать вручную прямо на странице;
* синхронизирует только новые лайки с прошлого раза одной кнопкой;
* сохраняет порядок лайков (свежие сверху, как в Яндексе);
* переживает обрыв и дневной лимит Spotify: просто нажмите кнопку ещё раз, работа продолжится с того же места;
* выгружает отчёт и список ненайденного в CSV (открывается в Excel, подходит для TuneMyMusic).

## 1. Что нужно заранее

1. **Windows 10/11** и **Python 3.10 или новее**. Скачайте с [python.org/downloads](https://www.python.org/downloads/).
   В установщике **обязательно отметьте «Add python.exe to PATH»**.
2. **Аккаунт Spotify с Premium** (без Premium Spotify с 2026 года не даёт пользоваться своим приложением для API).
3. Аккаунт Яндекса, где лежат ваши лайки.
4. Если Spotify в вашей стране недоступен, включите VPN на время входа и переноса
   (или укажите прокси в настройках сервиса, см. раздел «Если что-то не работает»).

## 2. Создайте приложение в Spotify (один раз, 3 минуты)

1. Откройте в Brave [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard) и войдите своим аккаунтом Spotify (тем, у которого Premium).
   Если просят, примите условия Developer Terms.
2. Нажмите **Create app** и заполните:
   * **App name**: любое, например `Yandex transfer`;
   * **App description**: любое;
   * **Redirect URIs**: впишите ровно `http://127.0.0.1:8888/callback` и нажмите **Add**;
   * в пункте **Which API/SDKs are you planning to use?** отметьте **Web API**;
   * согласитесь с условиями и нажмите **Save**.
3. Откройте созданное приложение → **Settings**, скопируйте **Client ID** (строка из 32 символов).
   Client Secret не нужен.
4. Если переносить будете **в другой** аккаунт Spotify, а не в тот, где создано приложение, добавьте его:
   в приложении вкладка **User Management** → впишите имя и e-mail этого аккаунта → **Add user**.

> Важно: адрес должен быть именно `127.0.0.1`, а не `localhost`, иначе Spotify не пустит.

## 3. Запуск

1. Скопируйте папку проекта куда удобно (сейчас она лежит в `C:\Users\SparrrxwMobile\Transfer music project`).
2. Дважды щёлкните **`START.bat`**. В первый раз он создаст окружение и установит библиотеки (1–2 минуты, нужен интернет).
3. Откроется браузер по умолчанию. Если это не Brave, откройте в Brave адрес **http://127.0.0.1:8888**.
4. Окно с чёрной консолью не закрывайте, пока работаете: это и есть сервис. Закрыли окно — сервис остановился.
   Все данные сохраняются в папке `data`, при следующем запуске всё продолжится.

## 4. Перенос по шагам (в интерфейсе)

### Шаг 1. Spotify
Вставьте **Client ID**, нажмите **Сохранить**, затем **Войти в Spotify** и разрешите доступ.
Вы вернётесь на страницу сервиса с надписью «Spotify подключён».

### Шаг 2. Яндекс Музыка (токен)
Яндекс не даёт официального API, поэтому сервис использует токен вашего аккаунта (как это делает
официальное приложение Яндекс Музыки). Токен даёт доступ к вашей музыке, никому его не передавайте.

**Способ А (основной):**
1. Нажмите **Получить токен**. Откроется страница входа Яндекса.
2. Войдите (если уже вошли, просто подтвердите).
3. Браузер перейдёт на `music.yandex.ru`, и на секунду в адресной строке появится адрес вида
   `https://music.yandex.ru/#access_token=y0_AgAAAA...&token_type=bearer&expires_in=...`
   Страница может сразу «съесть» хвост адреса. Тогда:
   * нажмите `Ctrl+Shift+I` (инструменты разработчика) → вкладка **Network** (Сеть) → отметьте **Preserve log** →
     снова нажмите **Получить токен** → в списке найдите запрос, начинающийся с `music.yandex.ru/#access_token=`
     или `verification_code`, и скопируйте его адрес;
   * или быстро нажмите `Esc` / кнопку «стоп» в момент перехода, чтобы адрес остался.
4. Вставьте **весь скопированный адрес** (или только сам токен `y0_...`) в поле и нажмите **Сохранить и проверить**.
   Появится «Яндекс Музыка подключена: ваш_логин».

**Способ Б:** установите в Brave расширение для получения токена Яндекс Музыки из Chrome Web Store
(ищите «Yandex Music Token»), войдите через него и скопируйте токен. Расширение стороннее, ставьте на свой риск.

Токен живёт долго, но не вечно. Если сервис скажет, что токен не принят, получите новый.

### Шаг 3. Загрузить треки из Яндекса
Три варианта, их можно сочетать:

* **А. Мои лайки.** Нажмите **Загрузить «Мне нравится»** (нужен токен из шага 2).
* **Б. Мои плейлисты.** Нажмите **Выбрать плейлисты…**, отметьте нужные (или «отметить все») и нажмите
  **Загрузить выбранные**. Каждый плейлист станет отдельным списком, а в Spotify — отдельным плейлистом.
* **В. По ссылке на открытый плейлист**, например лайки друга. Токен друга не нужен. Вставьте ссылку и нажмите
  **Загрузить по ссылке**. Подходят ссылки:
  * `https://music.yandex.ru/users/ЛОГИН/playlists/3` — «Мне нравится» пользователя (обычно номер 3);
  * `https://music.yandex.ru/users/ЛОГИН/tracks` — его лайкнутые треки;
  * `https://music.yandex.ru/playlists/…` — ссылка «Поделиться» на любой плейлист.

  Сначала сервис пробует открыть ссылку без токена. Если Яндекс не отдаёт плейлист анонимно, он повторяет попытку
  с **вашим** токеном из шага 2, так что на всякий случай подключите свой Яндекс. Плейлист должен быть открытым.

Все загруженные источники видны в блоке **«Загруженные списки»**. Кнопкой **Выбрать** переключаетесь между ними:
проверка (шаг 5), перенос (шаг 6) и отчёты относятся к выбранному списку. Повторная загрузка того же источника
безопасна: найденное не сбрасывается, новые треки добавятся.

### Шаг 4. Найти треки в Spotify
Нажмите **Начать поиск**. Поиск идёт сразу по всем загруженным спискам. Сервис бережёт дневной лимит Spotify:

* если Яндекс знает **ISRC** трека (международный код записи), сначала ищется по нему: это один запрос и почти
  стопроцентное совпадение, даже если в Spotify трек подписан латиницей;
* иначе один точный запрос «название + артист», и только если он не дал уверенного результата — запасные
  (транслитерация, свободный поиск);
* **один и тот же трек ищется один раз**: дубли из разных альбомов и плейлистов берут готовый результат,
  а все ответы Spotify кэшируются.

**Про дневной лимит.** Spotify в 2026 году ограничивает число запросов в сутки для личных приложений
и точные цифры не публикует. В сервисе стоит свой лимит **1500 запросов в день** (меняется в «Дополнительно»).
Когда лимит закончится, вы увидите сообщение «пауза до …». Просто запустите сервис и нажмите **Начать поиск**
снова после этого времени. Уже найденное не теряется.

> Если вы загружали лайки в прошлой версии, нажмите **Загрузить «Мне нравится»** ещё раз: подтянутся ISRC
> для треков, которые ещё не искали. Найденное и перенесённое не сбросится.

### Шаг 5. Проверить спорные
Откройте **Проверка**:
* **Спорные**: сервис нашёл похожие треки, но не уверен. Выберите правильный вариант и нажмите **Выбрать**,
  стрелка ↗ открывает трек в Spotify, чтобы послушать. Можно разом **Принять лучший вариант у всех спорных**.
* **Не найдено**: под каждым треком есть строка **ручного поиска**. Поправьте запрос (уберите лишнее, напишите
  латиницей, добавьте альбом) и нажмите **Найти**: результаты появятся в вариантах, выберите нужный.
  Ещё можно вставить ссылку на трек из Spotify («Поделиться» → «Скопировать ссылку на трек») или **Пропустить**.
* **Найдено автоматически**: можно пролистать и поправить, если что-то не то.

Выбор по треку применяется и к тому же треку в других загруженных плейлистах. Спорные и не найденные треки
**не переносятся**, пока вы их не подтвердите.

### Шаг 6. Перенести
Отметьте **в «Любимые треки»** и/или **в плейлист** и нажмите **Перенести** — переносится выбранный список.
Для «Мне нравится» по умолчанию отмечены «Любимые», для плейлистов — плейлист с тем же названием.
Чтобы разом перенести **все загруженные плейлисты** (каждый в свой плейлист Spotify), нажмите кнопку
в блоке «Загруженные списки». Повторный запуск ничего не дублирует, а только досылает новое.

Переносить можно частями, даже когда поиск стоит на паузе из-за лимита. Но в «Любимых» Spotify сортирует треки по
дате добавления, поэтому найденные позже окажутся выше. Если важен точный порядок лайков, в «Любимые» переносите
один раз в конце, а частями — в плейлист.

### Синхронизация новых лайков
После первого переноса на главной появится блок **«Синхронизация новых лайков»**. Кнопка
**Синхронизировать новые лайки** загружает из Яндекса только то, что вы лайкнули с прошлого раза, ищет это в Spotify
и переносит туда же, куда и в прошлый раз. Новые лайки окажутся в Spotify сверху, как и в Яндексе.
Запускайте, когда удобно, например раз в неделю. Лайки, которые вы сняли в Яндексе, из Spotify не удаляются.

### Отчёты
* **Отчёт CSV** в шапке: все треки выбранного списка, что нашлось, что перенесено.
* **Ненайденные CSV**: спорные, не найденные и пропущенные треки (на странице «Проверка» есть вариант
  «по всем спискам»). Колонки `Track name, Artist name, Album, Playlist name` подходят для импорта файлом
  в TuneMyMusic, если захотите попробовать найти остатки там.

## Передать другу и обновляться

Исходный код лежит на GitHub: **https://github.com/sparrrxw/yandex-music-to-spotify**. В репозитории нет ни токенов, ни прогресса:
папки `data` (база и токены), `python` (встроенный Python) и `.venv` в него не попадают.

**Первая установка у друга (без Python и git):**
1. Скачать портативную версию `TransferMusic-portable-win64.zip`: в ней уже есть встроенный Python
   (вы отправляете файл сами или берёте его со страницы Releases репозитория, если он там выложен).
2. Распаковать в любую папку и запустить `START.bat`. Инструкция для друга лежит внутри, в `README.txt`.

**Обновление:** закрыть окно сервиса и дважды щёлкнуть **`UPDATE.bat`**. Он скачает свежий код с GitHub,
заменит только файлы программы и обновит библиотеки. Папки `data` и `python` не трогаются, поэтому
весь прогресс (найденные треки, что уже перенесено, вход в Spotify и Яндекс) сохраняется. Если в папке
есть git-клон и установлен git, `UPDATE.bat` делает обычный `git pull`.

**Если у друга есть Python и git**, можно и так:
```
git clone https://github.com/sparrrxw/yandex-music-to-spotify.git
cd <папка>
START.bat
```
а обновляться через `git pull` или тот же `UPDATE.bat`.

С доступом к Spotify у друга два варианта:
* **у друга есть Premium**: он создаёт своё приложение на developer.spotify.com/dashboard и использует свой Client ID (рекомендуется);
* **у друга нет Premium**: вы добавляете его имя и e-mail Spotify в своё приложение (вкладка **User Management**, максимум 5 человек)
  и даёте ему свой Client ID. Дневной лимит запросов Spotify тогда общий на вас двоих.

## Если что-то не работает

| Сообщение / проблема | Что делать |
|---|---|
| `INVALID_CLIENT: Invalid redirect URI` при входе в Spotify | В настройках приложения Spotify должен быть ровно `http://127.0.0.1:8888/callback` |
| Spotify ответил **403** | Владелец приложения без Premium, или аккаунт, в который переносите, не добавлен в **User Management** |
| «Исчерпана дневная квота Spotify» / «пауза до …» | Это нормально: подождите до указанного времени и нажмите кнопку снова |
| Сайт Spotify или вход не открывается | Включите VPN. Либо в шаге 1 укажите прокси, например `socks5://127.0.0.1:1080` |
| Яндекс не принял токен | Получите токен заново. Если вы за границей с VPN, попробуйте выключить VPN для Яндекса или задать отдельный прокси для Яндекса |
| `START.bat` пишет «Не найден Python» | Скачайте портативную версию (в ней Python уже есть) или установите Python с галочкой «Add python.exe to PATH» |
| Порт 8888 занят | Закройте другую копию сервиса (второе окно консоли) |
| Хочу начать заново | Выберите список и нажмите «Дополнительно» → «Очистить выбранный список». Настройки и вход сохранятся |

## Как это устроено

* `app/yandex_client.py`: чтение лайков через библиотеку [yandex-music](https://pypi.org/project/yandex-music/).
* `app/spotify_client.py`: вход через OAuth PKCE (без Client Secret), поиск, `PUT /me/library`, `POST /me/playlists`,
  `POST /playlists/{id}/items` (эндпоинты Spotify после изменений февраля 2026), учёт лимитов и пауз.
* `app/matcher.py`: нормализация названий, транслитерация, оценка совпадения 0–100
  (≥ 85: автоматически, 60–85: на проверку, < 60: не найдено).
* `app/jobs.py`: фоновые задачи с возобновлением.
* `app/main.py` + `app/templates/`: веб-интерфейс.
* `data/transfer.db`: всё состояние (SQLite), включая токены. Не отправляйте эту папку другим людям.
  При обновлении программы база дополняется автоматически, прогресс сохраняется.

Тесты (для разработчика): `.venv\Scripts\python -m pip install pytest` и `.venv\Scripts\python -m pytest`.

## Ограничения и честные оговорки

* API Яндекс Музыки неофициальный. Чтение собственной медиатеки — серая зона пользовательского соглашения,
  на практике риск минимальный, но Яндекс может в любой момент что-то поменять.
* Часть русскоязычной музыки отсутствует в каталоге Spotify: обычно 5–20% треков не находится.
* Spotify ставит дату лайка = дате переноса, поэтому порядок сохраняется, а исходные даты нет.
