ПЕРЕНОС ЛАЙКОВ ИЗ ЯНДЕКС МУЗЫКИ В SPOTIFY
=========================================

Программа работает только на вашем компьютере. Ничего устанавливать не нужно:
Python и все библиотеки уже лежат внутри папки.

Нужно: Windows 10 или 11 (64-бит), аккаунт Яндекса с лайками и аккаунт Spotify.
Если Spotify в вашей стране недоступен, включите VPN на время работы.


ШАГ 0. ЗАПУСК
-------------
1. Распакуйте архив в любую папку (например, на Рабочий стол). Не запускайте прямо из архива.
2. Дважды щёлкните START.bat.
   Если Windows покажет синее окно «Windows защитила ваш компьютер», нажмите
   «Подробнее» → «Выполнить в любом случае».
3. Откроется браузер с адресом http://127.0.0.1:8888 (если не открылся, вставьте этот адрес
   в Brave/Chrome сами).
4. Чёрное окно не закрывайте, пока работаете: это и есть программа.
   Всё сохраняется в папке data, при следующем запуске продолжите с того же места.


ШАГ 1. ДОСТУП К SPOTIFY (выберите вариант А или Б)
--------------------------------------------------
Spotify с 2026 года пускает такие программы только через «приложение разработчика»,
и его владельцу нужен Spotify Premium.

Вариант А. Своё приложение (если у вас есть Spotify Premium) — рекомендуется.
  1. Откройте https://developer.spotify.com/dashboard и войдите в Spotify.
  2. Create app. Заполните:
       App name: любое, например Yandex transfer
       App description: любое
       Redirect URIs: http://127.0.0.1:8888/callback   (ровно так, нажмите Add)
       Which API/SDKs: отметьте Web API
     Согласитесь с условиями, Save.
  3. Откройте приложение → Settings → скопируйте Client ID (32 символа).

Вариант Б. Приложение друга (если у вас нет Premium).
  1. Сообщите владельцу приложения имя и e-mail вашего аккаунта Spotify.
  2. Он открывает своё приложение на developer.spotify.com/dashboard →
     вкладка User Management → вписывает ваше имя и e-mail → Add user.
     (В одно приложение можно добавить не больше 5 человек.)
  3. Он присылает вам свой Client ID.
  Учтите: дневной лимит запросов Spotify общий на все программы владельца,
  поэтому переносите не одновременно с ним.

Дальше в программе: вставьте Client ID → «Сохранить» → «Войти в Spotify» → разрешите доступ.


ШАГ 2. ЯНДЕКС МУЗЫКА
--------------------
Нужно, чтобы перенести СВОИ лайки. Если переносите чужой открытый плейлист по ссылке
(шаг 3, вариант Б), этот шаг можно пропустить, но лучше всё же сделать: если Яндекс
не отдаст плейлист без входа, программа попробует ещё раз с вашим токеном.

1. Нажмите «Получить токен» и войдите в Яндекс.
2. Браузер перейдёт на music.yandex.ru, и на мгновение в адресной строке будет
   https://music.yandex.ru/#access_token=y0_.....&token_type=bearer...
   Скопируйте весь этот адрес и вставьте в поле, нажмите «Сохранить и проверить».
3. Если адрес сразу пропадает: нажмите F12 → вкладка Network (Сеть) → отметьте
   Preserve log → снова «Получить токен» → найдите в списке строку с access_token
   и скопируйте её адрес.
Токен — это доступ к вашей музыке, никому его не пересылайте.


ШАГ 3–6. ПЕРЕНОС
----------------
3. Загрузка треков из Яндекса, варианты можно сочетать:
   А. «Загрузить «Мне нравится»» — все ваши лайки (нужен шаг 2).
   Б. «Выбрать плейлисты…» — ваши плейлисты, каждый станет отдельным плейлистом в Spotify.
   В. Ссылка на открытый плейлист → «Загрузить по ссылке». Подходят:
        https://music.yandex.ru/users/ЛОГИН/playlists/3   (лайки, обычно номер 3)
        https://music.yandex.ru/users/ЛОГИН/tracks
        https://music.yandex.ru/playlists/...             (ссылка «Поделиться»)
   Загруженное видно в блоке «Загруженные списки», кнопка «Выбрать» переключает список.
4. «Начать поиск» — найдёт треки в Spotify (сразу по всем спискам).
   У Spotify есть дневной лимит. Когда он закончится, программа напишет «пауза до …».
   После этого времени запустите START.bat и нажмите «Начать поиск» ещё раз — продолжит
   с того же места. Одинаковые треки ищутся один раз.
5. «Проверка» (вверху) — выберите правильные варианты для спорных треков. Для ненайденных
   есть строка ручного поиска: поправьте запрос и нажмите «Найти». Можно вставить ссылку
   на трек из Spotify («Поделиться» → «Скопировать ссылку») или пропустить трек.
6. «Перенести» — отметьте «в Любимые треки» и/или «в плейлист».
   Все загруженные плейлисты разом: кнопка в блоке «Загруженные списки».
   Повторный запуск ничего не дублирует.

Потом, чтобы перенести только новые лайки: кнопка «Синхронизировать новые лайки».

«Отчёт CSV» вверху — таблица для Excel: что нашлось и что перенесено.
«Ненайденные CSV» — то, что не нашлось (подходит для импорта в TuneMyMusic).


ОБНОВЛЕНИЕ ПРОГРАММЫ
--------------------
Закройте чёрное окно программы и дважды щёлкните UPDATE.bat. Он скачает свежую версию
с https://github.com/sparrrxw/yandex-music-to-spotify и обновит библиотеки.
Папки data (ваш прогресс и вход) и python не трогаются — всё продолжится с того же места.
Ничего, кроме интернета, не нужно: ни git, ни аккаунт GitHub.


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
- «Invalid redirect URI» при входе в Spotify: в приложении Spotify должен быть ровно
  http://127.0.0.1:8888/callback (не localhost).
- «Spotify ответил 403»: у владельца приложения нет Premium или ваш e-mail не добавлен
  в User Management (вариант Б).
- Spotify не открывается: включите VPN.
- Яндекс не принял токен: получите заново; если включён VPN, попробуйте без него.
- Окно сразу закрылось или пишет ошибку: сделайте скриншот и отправьте тому, кто дал программу.
- Начать заново: выберите список, затем «Дополнительно» → «Очистить выбранный список».

Папку data никому не отправляйте: там ваши токены.
